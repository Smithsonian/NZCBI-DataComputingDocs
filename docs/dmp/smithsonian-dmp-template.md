\# Smithsonian Data Management Plan (Ecology)



\## 1. Project Overview

Describe study objectives, ecological system, and data types.



\## 2. Data Types \& Formats

\- Observational data (CSV)

\- Sensor data (NetCDF)

\- Genomics (FASTQ, BAM)

\- Spatial data (GeoTIFF, Shapefile)



\## 3. Standards \& Metadata

\- Darwin Core / EML

\- ISO 19115 (geospatial)

\- README files with each dataset



\## 4. Storage \& Backup

\- Active storage on Hydra

\- Transfers via Globus

\- No primary storage on personal devices



\## 5. Access \& Sharing

\- Internal access via Hydra permissions

\- External collaborators via Globus Guest Collections

\- Embargoes applied where necessary



\## 6. Preservation \& Archiving

\- Final datasets archived in approved repositories

\- Metadata retained indefinitely



\## 7. Sensitive Data

\- Restricted access for endangered species locations

\- Compliance with Smithsonian policies



\## 8. Roles \& Responsibilities

\- PI: oversight and compliance

\- Data manager: organization and metadata

\- Analysts: reproducibility and documentation
